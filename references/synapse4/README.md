# Captures de référence Synapse 4

Déposer ici les captures fournies volontairement pour l'étude visuelle. Elles ne deviennent pas des assets de l'application et ne doivent pas être redistribuées dans le prototype.

## Réglages utiles

- PNG, fenêtre entière avec barre de titre et navigation, sans recadrage ni redimensionnement.
- Garder la même taille de fenêtre pour la série ; noter résolution écran, mise à l'échelle Windows (100/125/150 %), taille de fenêtre approximative et version Synapse.
- Masquer adresse mail, nom de compte et numéro de série si visibles.
- Capture au repos puis, si utile, une autre avec le menu ouvert, une zone sélectionnée ou un contrôle survolé.

## Première série prioritaire

1. `01-dashboard.png` : Dashboard avec les appareils visibles.
2. `02-basilisk-customize.png` : Basilisk V3 Pro 35K Phantom Green Edition, Customize au repos.
3. `03-basilisk-button-menu.png` : même page, bouton latéral sélectionné et panneau/menu d'affectation ouvert.
4. `04-basilisk-performance.png` : Performance, tous les stages DPI visibles.
5. `05-basilisk-lighting.png` : Lighting, luminosité et effets.
6. `06-profile-menu.png` : menu de profils ouvert.
7. `07-onboard-profiles.png` : mémoire embarquée si disponible.
8. `08-window-compact.png` : même application dans une fenêtre plus petite pour observer l'adaptation.

## Deuxième série

- BlackWidow V3 Mini HyperSpeed : Customize et Lighting, panneau d'affectation et profils si différents.
- Goliathus Chroma : page d'accueil/configuration et Lighting.
- Thunderbolt 4 Dock Chroma : onglets disponibles et Lighting.
- ARGB Controller : page générale, sélection d'un port/canal et réglages Lighting/LED.
- Paramètres desktop (fermeture/tray/auto-start), menu tray et menus déroulants utiles.

Les captures n'impliquent aucune demande d'écriture matérielle ou de changement firmware. Pour USB/2,4 GHz, indiquer simplement la connexion utilisée, sans devoir refaire toute la série. Ajouter un fichier `contexte.txt` avec les informations d'écran/version/connexion.
